🌱 WasteWise AI

CNN-Based Waste Classification for Smarter Waste Management (Coding Camp powered by DBS Foundation 2025)

Overview

WasteWise AI is a collaborative capstone project developed as part of the Coding Camp powered by DBS Foundation 2025 program. The project integrates Front-End, Back-End, and Machine Learning development to help users identify waste categories from images using a CNN model with MobileNetV2 architecture, classifying waste into 3 main categories and 15 subcategories.

🎯 Problem Statement & Objective

  • Challenge: Accurate waste identification is an important step in sorting, but users often find it difficult to determine the appropriate category of an item based solely on its appearance.
  • Solution: Developed an end-to-end image classification system recognizing 15 waste subcategories, integrated into a collaborative web platform to support automated sorting.

📊 Model Performance & Metrics

Evaluation Metric Result Specifications
Dataset Size Approx. 7,182 Images (3 Main Categories, 15 Subcategories)
Training Accuracy 100%
Validation Accuracy 87.68%
Average F1-score 0.83

💡 Key Technical Insights

  • MobileNetV2 Efficiency: Leveraging transfer learning with MobileNetV2 enabled fast feature extraction and efficient model deployment suitable for web integration.
  • Dataset Curation: Removing corrupted files and balancing open-source image datasets (including Kaggle's Waste Classification) successfully improved model stability across 15 subcategories.
  • Generalization Gap: The difference between training accuracy (100%) and validation accuracy (87.68%) highlights the importance of testing on unseen field data to prevent overfitting.
