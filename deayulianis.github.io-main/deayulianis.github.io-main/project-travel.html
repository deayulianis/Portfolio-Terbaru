✈️ Travel Shantuy Catalog

UI/UX Design & Web Programming Project — Travel & Culinary Catalog Website (Gunadarma University)

Overview

Travel Shantuy is a group assignment project for the Web Programming and Human-Computer Interaction (IMK) courses at Gunadarma University (Dec 2024 – Jan 2025). The website serves as a comprehensive travel and culinary catalog showcasing tourist destinations, local foods, detailed descriptions, and popular recommendations. Serving as the UI/UX Designer and System Analyst, I designed the interface in Figma and implemented core front-end components.

🎯 Problem Statement & Objective

  • Challenge: Travelers often struggle to find consolidated, well-structured information regarding local tourist attractions and regional culinary spots in a single, intuitive platform.
  • Solution: Designed and developed an interactive catalog platform featuring dedicated travel/culinary listings, detailed destination views, search/filter capabilities, and popular recommendations.

📑 Main Catalog Features

Feature Category Description & Components
Travel Catalog List of tourist attractions, destination details pages, photo galleries, and map locations.
Culinary Catalog Regional food lists, detailed food descriptions, and purchase/location guidelines ("where to buy").
Popular Recommendations Curated selection of trending culinary spots and tourism destinations based on popularity.

💡 My Contribution (UI/UX & System Analyst)

  • UI/UX Design: Designed the main application views and user flows in Figma to ensure an intuitive and engaging user experience.
  • Front-End Implementation: Developed the travel catalog page, culinary page, and reusable destination/culinary card components.
  • HTML & CSS Structure: Assisted the team in building the initial responsive HTML & CSS layout framework.
