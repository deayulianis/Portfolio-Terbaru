🖼️ Intel Image Classification CNN

Multi-Class Scene Classification & Deep Learning Model Deployment (TF-Lite & TFJS)

Overview

An end-to-end computer vision project leveraging a custom Convolutional Neural Network (CNN) architecture to classify natural scenery images into six distinct categories: buildings, forest, glacier, mountain, sea, and street. The pipeline covers automated data merging, train-val-test splitting, model training across 15 epochs, comprehensive evaluation via confusion matrix, and multi-format model conversion (TF-Lite and TensorFlow.js).

🎯 Problem Statement & Objective

  • Challenge: Automatically and accurately categorizing diverse natural and urban scenes from raw image data requires robust feature extraction and spatial pattern recognition.
  • Solution: Built a 4-layer Conv2D and MaxPooling pipeline combined with fully connected layers and Dropout regularization, trained on 11,920 merged images, achieving high performance and successful deployment packaging.

💡 Key Technical Insights & Evaluation

  • Class-Level Performance: The classification report demonstrates stellar results in categories like *forest* (F1-score: 0.95) and *sea* (F1-score: 0.87), proving the CNN's strong capability in capturing distinct textural and structural patterns.
  • Deployment Flexibility: Successfully converted the trained TensorFlow model into SavedModel, TensorFlow Lite (`.tflite`), and TensorFlow.js formats, enabling multi-platform deployment readiness.
  • Submission Packaging: Automated the packaging pipeline to bundle model artifacts, test label indices (`label.txt`), requirements, and README into a clean zip archive.
