💬 TikTok Review Sentiment Analysis

Indonesian Natural Language Processing & Lexicon-Based Sentiment Classification

Overview

An end-to-end Natural Language Processing (NLP) project analyzing 10,000 user reviews of the TikTok application in Indonesian. The pipeline covers complete text preprocessing (slang normalization, stopword removal, and Sastrawi stemming), lexicon-based sentiment labeling, exploratory data analysis via WordClouds and Treemaps, TF-IDF feature extraction, and machine learning classification using SVM, Random Forest, and Logistic Regression.

🎯 Problem Statement & Objective

  • Challenge: Processing unscripted Indonesian user reviews containing heavy slang, typos, and abbreviations to extract actionable user satisfaction insights.
  • Solution: Constructed an NLP pipeline with custom Indonesian slang mapping and Sastrawi stemming, followed by TF-IDF vectorization to train multiple supervised models for automated sentiment classification.

📊 Model Performance & Sentiment Distribution

Model Classifier Test Accuracy Precision / Recall / F1-Score (Positive Class)
Support Vector Machine (SVM) 90.80% Precision: 0.96 | Recall: 0.93 | F1: 0.94
Random Forest Classifier 90.70% Precision: 0.95 | Recall: 0.93 | F1: 0.94
Logistic Regression 90.40% Precision: 0.94 | Recall: 0.94 | F1: 0.94

Dataset Distribution (10,000 Total Reviews): Positive: 7,211 (72.1%) | Negative: 2,340 (23.4%) | Neutral: 449 (4.5%).

💡 Key Technical & Business Insights

  • High Model Reliability: All three models achieved over 90% accuracy on the test set, with Support Vector Machine (SVM) yielding the highest accuracy of 90.80%.
  • Slang & Stemming Impact: Normalizing regional slang terms and applying Sastrawi Indonesian stemming significantly reduced vocabulary noise before TF-IDF vectorization.
  • User Sentiment Highlights: Exploratory analysis revealed top positive drivers around content creation and entertainment ("bagus", "suka", "seru"), while negative feedback focused on technical issues ("blokir", "update", "bug").
